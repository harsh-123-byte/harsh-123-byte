 - Built a MERN-based financial intelligence platform integrating Gemini LLM for automated transaction/document
understanding and personalized financial insights.
- Developed document processing workflows for CSV/PDF bank statements, including extraction, duplicate detection,
validation, and transaction categorization.
- Implemented AI-assisted anomaly, risk, and opportunity detection with rule-based fallback mechanisms for reliable
operation during model/API limitations.

### ⚡ Chatify- Real-Time Chat Application

> **Stack:** Node.js · Express.js · React.js · Socket.IO · MongoDB

 
- Developed a real-time, full-stack messaging application using the MERN stack to facilitate seamless concurrent 1-to-1 user
communication.
- Implemented bi-directional, low-latency WebSocket communication via Socket.io to ensure instant message delivery and
